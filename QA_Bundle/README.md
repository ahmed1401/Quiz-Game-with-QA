# QA Bundle — Quiz Game

Ce répertoire regroupe toutes les livraisons QA du Sprint 1, classées pour un accès rapide :

| Dossier | Contenu |
|---------|---------|
| `01_UserStories/` | Référentiel fonctionnel complet (`PlanTest.md`). |
| `02_TestScope/` | Périmètre, stratégie et éléments à tester (`TestScope.md`). |
| `03_TestCases/` | Catalogue de cas (`TestCases.md`) et export tableur (`TestCasesSheet.csv`). |
| `04_TestPlans/` | Plans maîtres et dossiers intégrés (`MasterTestPlan.md`, `QA_FullDossier.md`). |
| `05_Reports/` | Rapports d'exécution, défauts, performance/sécurité et PV de recette. |
| `06_FinalReports/` | Synthèse finale livrable (Plan de test, Rapport des tests, Rapport de clôture). |

Les fichiers originaux restent à leur emplacement historique pour compatibilité, mais cette arborescence devient la référence pour toutes les revues QA.
