# 07.2 — Automatisation UI (Cypress)

## Vision
Automatiser les parcours Login → Quiz → Leaderboard sous Angular 18 pour fournir une régression E2E rapide, intégrable dans la CI et générant des captures/vidéos exploitables.

## Stack
| Outil | Version cible | Rôle |
|-------|---------------|------|
| Cypress 13.x | Runner e2e/comp | Exécution des specs.
| TypeScript 5.x | Langage | Typage & intellisense.
| `start-server-and-test` | ≥2.x | Orchestration démarrage serveur + tests.
| `eslint-plugin-cypress` | ≥2.x | Lint spécifique.

## Architecture recommandée
```
frontend/
├─ cypress.config.ts
├─ cypress/
│  ├─ fixtures/users.json
│  ├─ support/{commands.ts,e2e.ts}
│  └─ e2e/{auth.cy.ts,quiz.cy.ts,leaderboard.cy.ts,regression.cy.ts}
```
- `commands.ts` expose `cy.login`, `cy.authenticatedVisit`, etc. pour factoriser.
- `regression.cy.ts` enchaîne le flux complet (signup → quiz → leaderboard) et vérifie le `localStorage`.

## Suites et cas
| Spec | Scénarios cibles | Notes |
|------|------------------|-------|
| `auth.cy.ts` | Signup happy path, doublon email, login/logout, redirection forcée /auth guard. | Utilise fixtures.
| `quiz.cy.ts` | Sélection catégorie, déroulé complet, assertions sur couleur feedback, persistance high score. | Possibilité de stubber `/api/questions` via `cy.intercept`.
| `leaderboard.cy.ts` | Tri total score, message vide, navigation retour. | Tests sur DOM table.
| `regression.cy.ts` | Chaîne E2E, vérifications `localStorage`, leaderboard final. | Sert de smoke.

## CI & artefacts
```json
{
  "scripts": {
    "cy:run": "cypress run --browser chrome",
    "test:e2e": "start-server-and-test 'npm run start:test' http://localhost:4300 cy:run"
  }
}
```
- Exigence : temps total < 5 min, 0 flaky (1 retry max).
- Artefacts conservés dans `frontend/cypress/screenshots` et `frontend/cypress/videos`.
